The honest part

jamovi is R behind a spreadsheet — and that is a strength

jamovi is free and open source, and its design is deliberately extensible: a core set of analyses plus a library of modules you add when you need them, all powered by R. Because R is underneath, the analyses follow the same methods R users already trust, and advanced users can go deeper than the menus. If extensibility, R at the core and a zero price matter to you, jamovi is a strong choice and this page does not argue otherwise.

Magic Stat takes a different position. There is no module library and no R underneath: the analyses ship inside one application, share a single visual language, and are limited to what is included. The trade is deliberate — fewer moving parts to install and keep aligned, and an output path (APA table, figure, report) attached to every analysis rather than assembled afterwards.

The two are answering different questions. jamovi asks "how do I extend this?" Magic Stat asks "how do I get from this result to the manuscript?"

What it does

What is different from a module-based tool

  • One application, no module list. The analyses are in the app — there is nothing to browse, add or version separately.
  • A fixed, integrated method set: the ANOVA and regression families, GLM/GAM, mixed models and GEE, SEM and PLS-SEM, psychometrics and IRT, meta-analysis, time series, ecology and ordination, econometrics, medical statistics and spatial analysis — all with the same dialogs and the same reports.
  • Manuscript output on every run: APA tables copied into Word, figures exported as PNG, PDF or SVG, and an automatic report (.docx/.html/.md).
  • Not built on R. Magic Stat's engines are its own; there is no R installation to maintain. The cost is that you cannot drop into a lower-level language inside it the way a jamovi user can drop into R.
  • Local by default. Analysis runs on your computer; nothing is uploaded.
How it works

Open, choose, run, export

  1. Open a spreadsheet. CSV or Excel — no module or add-on is needed to read it.
  2. Choose the analysis. from the menu; if it is in the app it is simply there, with no install step.
  3. Run and read. the result, the assumptions and an interpretation appear together.
  4. Adjust if needed. the settings are controls in the dialog, documented in place.
  5. Export. table to Word, figure to the gallery, report to .docx/.html/.md.

Frequently asked

jamovi questions, answered honestly

Is jamovi free?

Yes — free, open source, and built on R. If free and extensible suit you, keep using it.

Can I add modules to Magic Stat?

No. It is one integrated application, not a modular platform. If adding modules matters, jamovi is the better-designed tool for that.

Does Magic Stat use R?

No. Its engines are its own, built in Python on numpy/scipy, statsmodels, scikit-learn and semopy. That means no R to install, but also no R to drop into.

Is it free?

No — a free 48-hour trial with no card, then US$1,400 per year.

What is the main difference?

jamovi is a platform you extend; Magic Stat is an application that ends in a manuscript artefact — an APA table, a figure and a report.
