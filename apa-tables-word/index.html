The problem

Everything that happens after the analysis

You run the test, get the numbers, and then the real work starts: rebuilding the output as a table that follows APA convention — the <.001 convention, exact p-values, group letters, means with standard deviations, the right number of decimals, and no vertical rules. Then you copy it into Word and the column widths collapse.

None of that is statistics. It is formatting, it is repetitive, and it is where a surprising share of the time in a paper goes.

What it outputs

A table that is already a paper table

  • APA convention built in. Means and standard deviations, exact p-values in a sibling column next to the <.001*** column, group letters as real superscripts rather than copied text.
  • Two versions of the same table. A concise one sized to fit an A4 page, and a complete detailed one — both ready to paste.
  • Copy Table pastes as a real table. Not an image and not mangled text: word processor table with booktabs-style rules, column widths taken from the content and a font size that adapts instead of overflowing.
  • The figure alongside the table. The plot is produced at publication quality, with the legend outside the plotting area and colour palettes designed for scientific figures.
  • An automatic report. Every analysis is collected into a report with its interpretation, the assumptions and the effect size, so you are not copying results somewhere before you forget where they were.

A quick practical check, if you want it: run one test on the built-in example dataset, hit Copy Table, and paste it into Word. The table either arrives intact or it does not — that is the whole promise of this page.
